Project Description
A Java-based simulation of an elevator system demonstrating Core Java skills, OOP principles, and collections framework usage. The elevator handles boarding, deboarding, direction changes and idle states based on user input or random rush hour simulation.

Technologies Used
Java (JDK 8+)
Collections Framework (HashMap, ArrayList)
Core OOP Concepts (Encapsulation, Abstraction)
Single-threaded Console Application

Features
Elevator moves up or down based on requests.
Multiple passengers can board from a single floor.
Automatically changes direction at top or bottom floors.
IDLE mode when no requests are pending.
Manual mode (user inputs) or Automatic rush hour simulation (random requests).
Smart management of boarding and deboarding.

 How It Works
Manual Mode:
Enter pickup (starting) floor and destination floor.
Elevator will pick you up and drop at the desired floor.
Automatic Mode:
Random pickup and destination requests are generated.
Elevator services all requests until idle.

How to Run the Project
You can either:
Open it in Eclipse / IntelliJ IDEA, OR
Compile and run manually using terminal.
